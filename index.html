Free Deployment & Automation Guide

Free Website Hosting & 5 AM Cron Automation

Complete setup guide to host this temple portal for free and configure automated 5:00 AM WhatsApp and Email greetings using free cron automation tools.

1. GitHub Pages + 5 AM Cron Action

  1. Upload index.html to a public GitHub repo.
  2. In Settings > Pages, set source branch to main for free website hosting.
  3. To automate 5 AM dispatches, add a GitHub Workflow file .github/workflows/morning5am.yml:
name: Morning 5AM Dispatch
on:
  schedule:
    - cron: '30 23 * * *' # 5:00 AM IST
jobs:
  dispatch:
    runs-on: ubuntu-latest
    steps:
      - run: curl -X POST https://your-backend-api.com/trigger-5am

2. Netlify Hosting + Scheduled Functions

  1. Drag and drop folder containing index.html on app.netlify.com/drop.
  2. Use Netlify Scheduled Functions with cron trigger @daily set for 05:00 AM.
  3. Connect free EmailJS API or Twilio WhatsApp API inside the function.

3. Vercel Hosting + Vercel Cron

  1. Import GitHub repository into Vercel.com for instant free SSL hosting.
  2. Add a vercel.json file with a cron schedule:
{
  "crons": [{
    "path": "/api/send-5am-wishes",
    "schedule": "30 23 * * *"
  }]
}

4. Firebase + Cloud Scheduler

  1. Deploy static site using firebase deploy.
  2. Use Firebase Cloud Functions v2 with onSchedule("0 5 * * *") to query devotee birthdays/anniversaries from Firestore and send automated morning WhatsApp & Emails.
